How this repo generates code

Gradle still embeds Ant. We register XJC as an Ant task, the same class old build.xml files used: com.sun.tools.xjc.XJCTask.

Then compileJava.dependsOn genJaxb so Spring never compiles against missing classes.

What XJC actually emits

XJC reads the XSD, not the full WSDL. Global elements become factory methods. Complex types become classes you import.
